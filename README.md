# Afiliado Store
### Curadoria de produtos e ofertas

Projeto em fase de concepção para uma vitrine digital de produtos, com possibilidade de trabalhar com links de afiliados e, futuramente, integrar outros modelos de operação de e-commerce.

[![Acessar repositório](https://img.shields.io/badge/REPOSITÓRIO-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/brunosg24/afiliado.store)

</div>

---

## ✦ Visão do projeto
A ideia é organizar produtos por categorias, destacar ofertas e facilitar o acesso do visitante às páginas de compra dos parceiros.

## Funcionalidades planejadas
- Vitrine de produtos com imagens e descrições.
- Organização por categorias e coleções.
- Links externos de afiliados.
- Área administrativa para gerenciar produtos.
- Layout responsivo.
- Avaliação futura de integrações com checkout e banco de dados.

## Pontos de atenção
Antes de publicar, será necessário definir as regras de divulgação de links afiliados, identificar claramente os parceiros comerciais, revisar políticas de privacidade e proteger qualquer área administrativa.

## Status
**Conceito inicial — sem aplicação implementada neste repositório.** As funcionalidades descritas representam o planejamento do projeto.
